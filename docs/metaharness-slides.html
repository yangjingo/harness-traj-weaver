Why

Foundation

Three Principles

1

Filesystem as Memory

No DB, no vector store — just versioned dirs you can read and diff.

2

Trace-Level Reasoning

Diagnose raw execution traces, not aggregate scores.

3

Search-Set Feedback

Human QA on search set only. Test-set never exposed.

Each principle has teeth — enforced by a concrete skill, not just a slide

Skill / Observe

traj — See What the Agent Saw

Reads Claude Code JSONL sessions, generates self-contained interactive HTML with TOC, foldable turns, thinking blocks, tool calls, and skill highlighting.

python skills/traj/scripts/generate_traj.py \ --input ~/.claude/projects/<project>/<session>.jsonl \ --output traj.html
Thinking blocks Tool calls Skill execs TOC nav
Don't read summaries — read the raw conversation. Thinking blocks reveal the agent's actual reasoning
Skills / Diagnose & Evaluate

metric + survey — Gate & Feedback

metric — Pre-commit code review

Reads git diff, scores every change against 4 Karpathy principles — over-engineering, drive-by edits, missing assumptions. Blocks commit below threshold.

python skills/metric/scripts/generate_dashboard.py \ --diff HEAD --goal "Add user auth"

survey — Terminal human QA

AskUserQuestion drives interactive Q&A after each skill execution. 27 questions across 7 sections (A–G), including 9 dynamic diff-aware questions. Answers archived as structured JSON.

Section A–F: static Section G: diff-aware quick 8q / full 27q
metric gates before commit · survey learns from humans after commit — together they close the quality loop

Hook + Developer Experience

Install

git clone https://github.com/yangjingo/harness-traj-weaver.git \ ~/.claude/skills/harness-traj-weaver bash ~/.claude/skills/harness-traj-weaver/scripts/install.sh

Two commands. Installs skill + hooks into .git/hooks/.

The Key Insight

Every Commit Has a Session

▷

Traceability

Any commit traces back to the exact conversation that produced it, via session ID

⚙

Diagnosis

Bug in a commit? Replay the session trace to see what the agent was thinking

↺

Feedback Loop

Session → trace → review → feedback → next session. Self-reinforcing quality.

★

Dogfooding

Meta-Harness reviews its own code via its own hooks. The reviewer reviews itself.

The session ID is the missing link — it connects a commit to the exact conversation that produced it
